# 가계부 PWA

개인 가계부 웹앱의 화면(프론트엔드)입니다. 정적 파일만으로 동작합니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (화면 · 스타일 · 로직) |
| `manifest.webmanifest` | PWA 설치 정보 |
| `sw.js` | 서비스워커 (앱 셸 캐시, 오프라인 열람) |
| `icon-192.png` · `icon-512.png` | 앱 아이콘 |

## 데이터

이 저장소에는 **데이터가 없습니다.** 가계부 기록은 별도의 비공개 스프레드시트에 있고,
앱은 실행 시점에 사용자가 입력한 서버 주소로 요청을 보냅니다.

- 서버 주소는 소스에 포함되어 있지 않으며, 브라우저 `localStorage`에만 저장됩니다
- 모든 데이터 요청은 PIN 인증으로 발급된 토큰이 있어야 응답을 받습니다
- 카테고리 · 결제수단 목록도 서버에서 내려받습니다

따라서 이 저장소를 복제해도 빈 로그인 화면만 열립니다.

## 사용

첫 실행 시 **서버 주소**와 **PIN**을 입력하면 해당 기기에 저장됩니다.
브라우저 메뉴에서 홈 화면에 추가하면 독립 앱처럼 실행됩니다.
